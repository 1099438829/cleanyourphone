# 小米 / 红米 (MIUI 12-14 / HyperOS 1-2) — 手动关闭广告与优化设置

ADB 列表: `debloat.txt`(卸载/禁用广告包)。
下面是设置里才能关的开关——**广告主要来源是个性化推荐服务, 两个一起做才干净**。

## 一、关闭广告(设置内操作)

1. **关闭个性化广告(最重要)**
   设置 → 密码与安全 → 系统安全 → **广告服务** → 关闭"个性化广告推荐"
2. **关闭负一屏内容推荐**
   设置 → 桌面 → **智能助理** → 关闭(或卸载 `com.miui.personalassistant`)
3. **天气广告**
   天气 App → 右上角"···" → 设置 → 关闭"个性化推荐/天气资讯卡片"
   (或卸载 `com.miui.weather2`, 用第三方天气)
4. **浏览器资讯**(保留浏览器时)
   浏览器 → 我的 → 设置 → 关闭"资讯推送/通知", 首页下拉关掉"资讯"版块
5. **手机管家推荐内容**(保留管家时)
   手机管家 → 右上角设置 → 关闭"推荐内容/垃圾清理结果广告"
6. **全局搜索**
   设置顶部搜索"搜索"→ 搜索管理 → 关闭"热门搜索/资讯推荐"
7. **文件管理/下载管理**的"热门应用"推荐, 在对应 App 设置内关闭

> 小技巧: 设置页面顶部都有搜索框, 直接搜"广告""推荐"通常能直达开关。

## 二、优化设置

1. **动画提速**: 设置 → 更多设置 → 开发者选项 → 三个动画缩放全部设为 `0.5x`(或关闭)
2. **关闭系统自动更新**: 设置 → 我的设备 → 系统版本 → 右上角"···" → 关闭"自动下载/智能更新"
3. **自启动管理**: 设置 → 应用设置 → 权限 → 自启动管理 → 只保留微信等必要应用
4. **后台限制**(可选): 开发者选项 → 后台进程限制 → 不超过 4 个(省内存但可能杀后台)
5. **关闭用户体验计划**: 设置顶部搜索"体验改进计划" → 关闭
6. **省电**: 设置 → 省电策略 → 对不常用 App 设为"智能限制后台运行"

## 三、注意事项

- **保留** `com.miui.securitycenter`(手机管家): 权限管理、拦截、查找设备都依赖它
- **保留** `com.miui.home`(桌面): 脚本安全规则会自动拦截, 无需担心
- 卸载 `com.android.browser` 后, 部分"打开网页"的场景仍可用(系统保留 WebView)
- 卸载的应用随时可恢复: `tools/restore.sh examples/xiaomi-hyperos/debloat.txt`
- OTA 升级后运行 `tools/check.sh examples/xiaomi-hyperos/debloat.txt --fix`
