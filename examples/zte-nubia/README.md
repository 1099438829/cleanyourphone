# 中兴 / 努比亚 / 红魔 国行 (MyOS 11-14) — 手动关闭广告与优化设置

> 列表: [`debloat.txt`](debloat.txt) · 设置: [`settings.conf`](settings.conf)
> 适用: 中兴 Axon 系列、努比亚 Z 系列、红魔 REDMAGIC(MyOS 内核)

## 一、关闭广告(设置内操作)

1. **努比亚浏览器资讯/广告**
   浏览器 → 我的 → 设置 → 关闭「资讯推荐 / 个性化推荐」
   (或直接卸载 `cn.nubia.browser`, 见 debloat.txt)
2. **应用商店推荐**
   应用中心 → 我的 → 设置 → 关闭「个性化推荐 / 推送通知」
3. **个性化广告**
   设置 → 隐私 → 广告与隐私 → 关闭「个性化广告推荐」
   (MyOS 路径个别版本为 设置 → 安全与隐私 → 广告)
4. **负一屏 / 智慧服务卡片**
   桌面左滑 → 右上角设置 → 关闭「智慧服务 / 推荐卡片」
   (或卸载 `cn.nubia.edge`)
5. **推送与通知**
   设置 → 通知与状态栏 → 逐个关闭不需要的应用通知; 营销推送多来自 `cn.nubia.neopush`

## 二、优化设置

1. **动画提速**: 设置 → 关于手机 → 连点版本号 7 次 → 开发者选项 → 三个动画缩放改 `0.5x`
2. **关闭系统更新自动下载**: 设置 → 系统更新 → 右上角「···」→ 关闭自动下载
3. **自启动管理**: 设置 → 应用 → 自启动管理(或 权限管理 → 自启动)
4. **关闭用户体验改进**: 设置顶部搜索「用户体验」→ 关闭
5. **红魔游戏空间**: 游戏空间内设置 → 关闭推荐与推送(不用可禁用 `cn.nubia.gamenotes`)

## 三、版本差异(重要)

| MyOS 版本 | 卸载行为 | 建议 |
| --- | --- | --- |
| MyOS 11 / 12 (Android 11/12) | `pm uninstall --user 0` 基本可用 | 清单里的 uninstall 直接执行 |
| MyOS 13 (Android 13) | 少数系统应用卸载被拒, 自动降级禁用 | 正常执行, 看失败项 |
| MyOS 14 (Android 14) | 拦截增多, 建议先预演 | `--dry-run` → `--batch 20` |

- 版本识别: `python3 tools/phone.py rom`
  MyOS 的版本号通常只在 `ro.build.display.id` 里(如 `MyOS13.0.2_NX729J`),
  工具会自动从中提取; 识别不到时手动指定 `--version myos:13`

## 四、注意事项

- **保留** `cn.nubia.accounts`(努比亚账号, 删了会退出登录)
- **保留** `cn.nubia.harassintercept`(骚扰拦截, 与电话功能相关)
- **保留** `cn.nubia.faceid`(人脸解锁)、`cn.nubia.myfile`(文件管理)
- 红魔机型的游戏肩键映射在 `cn.nubia.keymapcenter`, 不用肩键可禁用
- 老机型(Z17 及更早)包名可能为 `cn.nubia.*` 的旧命名, 列表中不存在的包会自动跳过
