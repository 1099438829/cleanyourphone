# 荣耀 (MagicOS 7/8/9) — 手动关闭广告与优化设置

## 一、关闭广告(设置内操作)

1. **限制广告跟踪(最重要)**
   设置 → 隐私 → **广告与隐私** → 打开"限制广告跟踪"
2. **杂志锁屏**(锁屏广告主要来源)
   设置 → 桌面和壁纸 → **杂志锁屏** → 关闭
3. **智慧搜索资讯/热搜**
   设置 → 智慧助手 → 智慧搜索 → 关闭"资讯/热搜/个性化推荐"
4. **服务推荐/玩机技巧**
   设置 → 智慧助手 → 关闭个性化推荐类开关(或卸载 `com.hihonor.tips`)
5. **浏览器资讯**(保留浏览器时): 浏览器 → 我的 → 设置 → 关闭资讯/个性化推荐
6. **应用市场推荐**: 应用市场 → 我的 → 设置 → 关闭"个性化推荐"

## 二、优化设置

1. **动画提速**: 设置 → 系统和更新 → 开发人员选项 → 三个动画缩放设为 `0.5x`
2. **关闭自动下载更新**: 设置 → 系统和更新 → 软件更新 → 关闭"WiFi 下自动下载"
3. **关闭用户体验计划**: 设置 → 系统和更新 → 用户体验改进计划 → 关闭
4. **应用启动管理**: 设置 → 应用 → 应用启动管理 → 按需关闭自启动
5. **电池**: 设置 → 电池 → 关闭"性能模式"(发热场景)

## 三、注意事项

- MagicOS 与华为 EMUI/HarmonyOS 包名高度相似(`com.hihonor.*` 与 `com.huawei.*` 并存), 两个列表可互相参考
- **保留** `com.hihonor.cloud`(云服务)与查找设备
- 锁屏杂志关闭后若仍出现广告, 检查是否装过第三方锁屏/主题, 或重装官方主题
