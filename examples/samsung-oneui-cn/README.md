# 三星国行 (One UI 5/6/7/8) — 手动关闭广告与优化设置

## 一、关闭广告(设置内操作)

1. **Samsung Free(负一屏资讯, 头号来源)**
   主屏幕向右滑动进入 Samsung Free → 右上角"菜单/设置" → 关闭
   (设置 → 主屏幕 → 关闭"Samsung Free"; 或卸载/禁用 `com.samsung.android.app.spage`)
2. **营销/个性化信息**
   设置 → 隐私权 → 自定义服务/营销信息 → 按提示关闭(不同版本路径略有差异,
   可在设置顶部搜索"营销""广告"尝试直达)
3. **浏览器资讯**(保留浏览器时): 浏览器 → 快捷栏"资讯" → 关闭, 或菜单 → 设置 → 关闭个性化
4. **应用商店推荐**: 应用商店 → 我的 → 设置 → 关闭"个性化推荐"
5. **三星视频/音乐**: 卸载后入口消失(见 `debloat.txt`)

## 二、优化设置

1. **动画提速**: 设置 → 关于手机 → 软件信息 → 连点"版本号"7 次 → 返回 → 开发者选项 → 三个动画缩放设为 `0.5x`
2. **关闭自动更新**: 设置 → 软件更新 → 关闭"自动下载更新"
3. **关闭营销信息**: 设置 → 帐户与备份 → 管理帐户 → Samsung account → 关闭营销推送(如有)
4. **电池**: 设置 → 常规管理 → 电池 → 更多电池设置 → 关闭"受保护的应用"中不必要的应用
5. **Bixby**: 不用可按音量-键关闭 Bixby 语音(或卸载 `com.samsung.android.svoice`)

## 三、注意事项

- **保留** `com.samsung.android.scloud`(三星云)与 `com.samsung.android.fmm`(查找手机)
- **保留** `com.samsung.android.spay`(Samsung Pay): 绑定公交卡/银行卡者默认保留
- 国行 Samsung Free 关闭后, 负一屏仍可放小组件

## 四、版本差异

- One UI 5/6/7 对系统应用卸载限制较少, `pm uninstall --user 0` 多数可用
- 版本识别: `python3 tools/phone.py rom`(看 `ro.build.version.oneui`, 60100 = 6.1)
- 国行与港版/国际版预装差异大, 列表中不存在的包会自动跳过
