# 魅族 (Flyme 9/10/AI) — 手动关闭广告与优化设置

## 一、关闭广告(设置内操作)

1. **浏览器资讯/广告**(头号来源)
   浏览器 → 我的 → 设置 → 关闭"资讯推送/个性化推荐/广告"
   (或卸载 `com.meizu.browser`)
2. **视频/音乐推荐**: 卸载 `com.meizu.media.video` 后入口消失
3. **应用商店推荐**: 应用商店 → 我的 → 设置 → 关闭"个性化推荐"
4. **锁屏/主题广告**: 主题App 内 → 我的 → 设置 → 关闭推荐

## 二、优化设置

1. **动画提速**: 设置 → 辅助功能 → 开发者选项 → 三个动画缩放设为 `0.5x`
2. **关闭自动更新**: 设置 → 系统更新 → 右上角 → 关闭"自动下载"
3. **关闭体验改进计划**: 设置顶部搜索"体验改进计划" → 关闭
4. **手机管家**(保留时): 手机管家 → 设置 → 关闭"推荐内容"
5. **自启动管理**: 设置 → 应用管理 → 权限管理 → 自启动 → 按需关闭

## 三、注意事项

- **保留** `com.meizu.mstore`(应用商店)、`com.meizu.cloud`(云服务)、`com.meizu.flyme.launcher`(桌面)
- Flyme 推送(`com.meizu.flyme.push`)卸载后部分应用可能收不到推送, 默认保留

## 四、版本差异

- Flyme 8/9/10 对系统应用卸载限制较少, `pm uninstall --user 0` 多数可用
- Flyme 11(AI 终端)起部分系统组件改为不可卸, 工具会自动降级为禁用
- 版本识别: `python3 tools/phone.py rom`(看 `ro.flyme.version`)
- Flyme 本身广告与预装很少, 清理重点是个性化推荐与统计上报
