# 联想 ZUI / 拯救者 Legion 国行 (ZUI 14-16) — 手动关闭广告与优化设置

> 列表: [`debloat.txt`](debloat.txt) · 设置: [`settings.conf`](settings.conf)
> 适用: 联想拯救者 Y70/Y90、moto 之外的联想自有 ZUI 机型

## 一、关闭广告(设置内操作)

1. **联想应用中心推荐**
   应用中心 → 我的 → 设置 → 关闭「个性化推荐 / 应用更新提醒」
   (或卸载 `com.lenovo.leos.appstore`)
2. **浏览器资讯**
   浏览器 → 我的 → 设置 → 关闭「资讯推荐 / 个性化广告」
   (或卸载 `com.zui.browser`)
3. **个性化广告**
   设置 → 隐私 → 广告 → 关闭「个性化广告推荐」
4. **负一屏 / 乐窗**
   桌面右滑 → 设置 → 关闭「智能推荐 / 乐窗卡片」
5. **游戏中心**: 游戏中心内设置 → 关闭推荐与推送

## 二、优化设置

1. **动画提速**: 设置 → 关于手机 → 连点「版本号」7 次 → 开发者选项 → 动画缩放 `0.5x`
2. **关闭系统更新自动下载**: 设置 → 系统更新 → 右上角设置 → 关闭自动下载
3. **自启动管理**: 设置 → 应用 → 自启动管理
4. **关闭用户体验计划**: 设置顶部搜索「用户体验」→ 关闭
5. **联想 One(手机-电脑互联)**: 不用可禁用 `com.zui.continuity`

## 三、版本差异(重要)

| ZUI 版本 | 卸载行为 | 说明 |
| --- | --- | --- |
| ZUI 14 (Android 12) | `pm uninstall --user 0` 基本可用 | 直接卸载 |
| ZUI 15 (Android 13) | 基本可用 | 同上 |
| ZUI 16 (Android 14) | 少数系统组件卸载被拒 | 自动降级禁用 |

- 版本号在 `ro.build.display.id`(如 `ZUI15.0.1`), 工具自动提取;
  识别不到时手动指定 `python3 tools/phone.py rom --version zui:15`

## 四、注意事项

- **保留** `com.zui.camera`(相机)、`com.zui.filemanager`(文件管理)
- **保留** `com.zui.safecenter`(安全中心, 权限与病毒扫描入口)
- **保留** `com.lenovo.lsf.user`(联想账号, 删了会退出登录)
- 主题覆盖层(`com.zui.*.overlay.*`)只换图标/皮肤, 卸载无功能影响, 但**不要**动
  `com.zui.android.overlay.common`(系统通用配置)
- 拯救者机型的 Legion 游戏空间若不需要, 可在应用管理里直接停用
