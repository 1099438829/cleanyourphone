# vivo / iQOO (OriginOS 1-4 / Funtouch OS 10-13) — 手动关闭广告与优化设置

## 一、关闭广告(设置内操作)

1. **个性化广告推荐**
   设置 → 隐私 → **广告与隐私/广告推荐** → 关闭"个性化广告推荐"
   (部分版本路径: 设置 → 更多设置 → 隐私; 也可在设置顶部搜索"广告"直达)
2. **锁屏杂志/阅图**(锁屏广告来源)
   设置 → 桌面、锁屏与壁纸 → 锁屏设置 → 关闭"杂志锁屏/阅图"
3. **浏览器资讯**(保留浏览器时)
   浏览器 → 我的 → 设置 → 关闭"资讯推送/个性化推荐"
4. **软件商店推荐**: 软件商店 → 管理 → 设置 → 关闭"个性化推荐/推送"
5. **全局搜索资讯**: 设置 → 系统应用设置 → 全局搜索 → 关闭"资讯/热搜"
6. **游戏中心/游戏魔盒**: 各自应用内设置 → 关闭推荐与推送

## 二、优化设置

1. **动画提速**: 设置 → 系统 → 开发者选项(连点版本号 7 次开启) → 三个动画缩放设为 `0.5x`
2. **关闭自动更新**: 设置 → 系统升级 → 右上角"设置" → 关闭"智能升级/自动下载"
3. **关闭体验改进计划**: 设置顶部搜索"体验改进计划" → 关闭
4. **i管家**(保留时): i管家 → 设置 → 关闭"推荐内容"
5. **自启动管理**: 设置 → 应用与权限 → 权限管理 → 自启动 → 按需关闭
6. **电池**: 设置 → 电池 → 后台高耗电 → 限制不常用应用

## 三、注意事项

- **保留** `com.bbk.account`(vivo 账号)与 `com.vivo.wallet`(钱包): 云服务、查找手机、支付都依赖它们
- **保留** `com.vivo.easyshare`(互传): 换机传输依赖它
- 卸载 `com.vivo.browser` 后, 微信内打开网页等场景不受影响(系统 WebView 保留)

## 四、版本差异(重要)

| 版本 | 卸载行为 | 建议 |
| --- | --- | --- |
| OriginOS 1.0 / Funtouch 11 (Android 11) | 基本可用 | 直接卸载 |
| OriginOS 2.0 / Funtouch 12 (Android 12) | 基本可用 | 直接卸载 |
| OriginOS 3 (Android 13) | 基本可用 | 直接卸载 |
| OriginOS 4 (Android 14) | 部分应用卸载后会自动恢复 | `check --fix` 定期复查 |
| OriginOS 5 (Android 15) | 拦截增多 | `--prefer-disable` + 分批 |

- 版本识别: `python3 tools/phone.py rom`(OriginOS 看 `ro.vivo.os.version`,
  老机型 Funtouch 看 `ro.build.version.funtouch`)
